FETCH LAB 2.0
=============

Интерактивный мультимедийный тренажёр:
«Асинхронное взаимодействие клиентской части информационной системы
с сервером средствами JavaScript».

ЗАПУСК
1. Распаковать архив.
2. Открыть index.html в Chrome / Edge / Firefox.
3. Интернет не требуется.

ЧТО ДОБАВЛЕНО В 2.0
- системный GUIDE с эффектом печатающегося текста;
- краткая теория непосредственно внутри каждого этапа;
- кнопка «Подробнее»;
- «рентген процесса»;
- временная шкала запроса;
- анимированный HTTP-пакет клиент → сервер → клиент;
- drag-and-drop последовательностей;
- drag-and-drop кода;
- HTTP Lab;
- Response Lab;
- Promise Lab;
- режим «Сломай систему»;
- Network / Console для диагностики;
- практические задания с уменьшающейся помощью;
- подсказки и счётчик ошибок;
- финальная комплексная миссия;
- сохранение прогресса через localStorage.

Методическая логика:
мини-теория → действие → визуальный результат → практика → диагностика → самостоятельная миссия.

Примечание:
Редактор кода использует учебный автотест по ключевым конструкциям и не
исполняет произвольный JavaScript пользователя. Это позволяет безопасно
запускать тренажёр как обычный локальный HTML-файл.

ВЕРСИЯ 2.6 — NETWORK VISUAL
В «Живом запросе» восстановлена и расширена визуализация сети:
— GET /api/schedule появляется у браузера при fetch();
— на этапе HTTP-запроса движется к серверу;
— у сервера фиксируется во время обработки;
— Response 200 OK отдельной зелёной плашкой движется обратно;
— показываются Method, URL, статус, Content-Type и JSON Body;
— response.json() визуально преобразует тело ответа в JavaScript object;
— затем показывается содержимое const data;
— на DOM-этапе отмечается, что сетевой обмен уже завершён.

ВЕРСИЯ 3.1 — PHP STACK
Учебная модель приведена к стеку HTML + CSS + чистый JavaScript + PHP + БД.
Главный пример теперь использует реальный путь api/schedule.php вместо абстрактного /api/schedule.
В «Живом запросе» добавлены отдельные этапы: веб-сервер запускает schedule.php, PHP получает данные (или обращается к БД), json_encode() формирует JSON, затем Response возвращается в JavaScript.
Добавлена визуальная структура проекта и пояснение, что PHP выполняется на сервере, а браузер получает результат его выполнения.
Маршрут, HTTP Lab, Promise Lab, Break/Debug Lab, практика и финальная миссия приведены к PHP-примерам.
HTTP-статусы сохранены отдельным модулем.
